Powers Tool WebUI 使用者指南

本指南供取得已建置 WebUI 啟動器的操作員使用，說明如何檢查與控制支援的直流電源供應器。Powers Tool 的架構不綁定特定廠牌；目前硬體支援範圍以 Supported Models 所記載的 Product scopes 為準；未知或未註冊的 live hardware 會 fail closed。本文聚焦一般本機 WebUI 操作，不涵蓋開發環境細節。API、驗證與 UI 變更邊界請參閱 WebUI README 與 WebUI 變更規則。

啟動 WebUI

使用本機 shared onedir build 時，請雙擊 bundle 中的 WebUI 啟動器：

dist\powers-tool\powers-tool-webui-launcher.exe

若要從 PowerShell 確認本機 bundle launcher 版本：

.\dist\powers-tool\powers-tool-webui-launcher.exe --version

正式 Windows release 請解壓縮帶版本號的 Desktop ZIP，並從 application root 啟動 Desktop shell：

powers-tool-<version>-windows-x64.zip
\powers-tool-<version>\Powers Tool.exe

不帶命令列選項時，啟動器會先保持隱藏，從 7999 開始自動嘗試，最多再測試 99 個較高的連接埠。啟動成功且 /api/health 回報就緒後，瀏覽器才會開啟；此時啟動器顯示精簡的 Running 視窗，包含實際 URL、執行狀態與 Quit。

只有全部自動候選連接埠都已被占用時，才會顯示完整的手動連接埠視窗。輸入另一個本機連接埠並按下 Start；若該連接埠仍被占用，視窗會保留以便再次修改。其他啟動錯誤不會轉入手動備援，而會保留原始錯誤、完成清理並以非零狀態結束。

從 PowerShell 使用 --port 可指定單一固定連接埠；只有同時提供 --auto-port 時，才會繼續嘗試其他連接埠：

.\dist\powers-tool\powers-tool-webui-launcher.exe --port 9000
.\dist\powers-tool\powers-tool-webui-launcher.exe --port 9000 --auto-port

若瀏覽器沒有自動開啟，請開啟啟動器顯示的實際 URL。使用預設連接埠時為：

http://127.0.0.1:7999/

開發人員或原始碼簽出使用者，請參閱 WebUI README 取得終端機指令、API、驗證與建置說明。

WebUI 在可存取儀器的同一台 Windows 電腦上執行，是本機工具而非雲端服務。關閉瀏覽器分頁不一定會停止伺服器；完成操作後請使用啟動器的 Quit，或停止終端機程序。

Desktop Shell

Source checkout 使用者可以從 desktop/ 執行 Electron Desktop shell：

Set-Location .\desktop
npm ci
npm start

這個 shell 顯示現有 WebUI，並使用 private WebUI Host。primary display 足夠時，視窗初始大小為 1920x1080；否則會 clamp 到 primary display work area。允許多個 Desktop instance 操作不同的實體儀器，但不可同時讓不同 client 操作同一個 physical instrument resource。

瀏覽器語言

主介面右上方提供「外觀」與「語言」兩個標示清楚的控制項。語言按鈕會顯示目前 locale：English 顯示 English，繁體中文顯示 繁體中文；accessible name 則描述點擊後要切換到的語言。

切換會在 執行階段立即生效，不需要 重新載入頁面，並保留目前頁面狀態，包括：

  • execution mode；
  • resource 與 identity selection；
  • command form；
  • workflow editor；
  • Job History 與 Job Result；
  • Result Detail；
  • Live Data 顯示狀態。

語言切換只改變瀏覽器 presentation，不會建立 HTTP request、Job 或 workflow action，也不會建立、停止或以其他方式影響 EventSource。

外觀控制會顯示目前的 System / Light / Dark 主題偏好，點擊後依序切換至下一個偏好。System 會遵循作業系統的 prefers-color-scheme。主題偏好會透過同一個 loopback browser 的 powers-tool.webui.theme cookie 保留；Electron Desktop shell 會使用該 cookie 同步 native window theme。

選定的主題會套用至主要的 panels、cards、fields 與 status surfaces，不只改變頁面背景。

深色主題下，主要控制項、狀態文字，以及不可用或停用的控制項，會在深色 surface 上維持足夠辨識度。

以下 machine-facing values 保持原值且不翻譯：command IDs、model IDs、VISA resources、API payload/schema、SCPI、raw diagnostics 與原始錯誤內容。

English 是 source/fallback locale。語言偏好會保留在相同瀏覽器中；如果 browser storage 不可用，WebUI 會安全 fallback，不影響正常操作。

畫面總覽

此頁面是儀器控制主控台，主要區域包括：

  • Execution mode：頁面內的 Real、Simulate 或 Dry-run 模式；重新載入頁面時一律回到 Real。
  • VISA resource：Real 命令工作所使用的明確儀器位址。
  • Live resource：由 Scan Device 探索到的資源。
  • Scan Device：搜尋目前可回應的 VISA 資源並填入選擇器。
  • Live Data：唯讀的通道卡片與狀態指示。
  • Basic command：各通道的 Voltage、Current、Set 與輸出控制。
  • Show more commands：開啟進階命令列與自動生成表單。
  • Job Result：最近提交的工作及其狀態。
  • Result Detail：所選工作的原始 JSON 詳細資料。

所有會影響硬體的工作仍必須明確提出，並通過相應的授權、確認與 Core 安全檢查。

首次使用

在檢查新電腦、VISA runtime、連線或電源供應器設定時，請使用此流程。

  1. 確認電源供應器與連接的受測物 (DUT) 均可安全查詢。
  2. 啟動 WebUI 並開啟本機瀏覽器頁面。
  3. 點擊 Scan Device。
  4. 選擇目標實機資源或將其複製到 VISA resource。
  5. 啟動 Live Data 以確認唯讀通訊與通道狀態。
  6. 在執行任何影響輸出的命令前，請先檢閱型號身分、輸出狀態、程式設定點以及保護狀態。
  7. 只有在目標通道與設定點確認安全後，才使用 Basic command (基本命令) 或進階命令列。

當可能連接多台儀器時，請勿用猜測的方式選擇資源。

資源掃描

Scan Device 會執行啟用實機篩選的資源探索，只顯示目前可回應的資源，而不是過時的 VISA 快取項目。

第一個有效結果會自動選取並複製到 VISA resource，同時執行一次唯讀身分辨識，以評估精確的產品級實機支援範圍。改選其他資源時也會重新評估。這個流程不會啟用輸出、不會修改儀器設定，也不需要實機寫入授權。您仍可手動輸入操作員已知的 VISA 資源。

Device options 包含執行模式；在 Real 模式還會顯示 Expected model。一般實機操作請保留 Auto-detect，由連線儀器的 *IDN? 決定實際型號。齒輪圖示左側的 Supported devices / 支援裝置 按鈕會開啟唯讀清單，顯示目前 Product-open 且 WebUI 可使用的 system_visa 連線（廠商、型號、連線方式）。選擇 Require <model> 時，它只用於前端規劃與預期型號安全護欄：若連線儀器不符，Core 會在設定或寫入 SCPI 前拒絕；它不會強制選用該型號的驅動程式。

一般型號選單由 Core 的 Product-active metadata 產生；目前支援的型號與 exact connection／backend scopes 以 Supported Models 為準。未知、已移出範圍、missing 或 pending scopes 會維持 fail closed。WebUI 使用正常 Product policy 與預設 system-VISA 後端，沒有後端選擇器或 validation mode。

若掃描不到可用資源，請檢查儀器電源、纜線、VISA 驅動程式可見度，以及是否有其他程式占用儀器。

即時資料 (Live Data)

Live Data 是一個唯讀監控器。它會定期讀取所選資源，更新通道卡片，並顯示 WebUI、命令與即時監控狀態。

在執行輸出命令前使用 Live Data 來確認：

  • 預期的型號有回應；
  • 測量到的電壓/電流看起來合理；
  • 清楚了解目前的程式設定點；
  • 確知目前的輸出狀態；
  • 支援 OVP/OCP 時可看見其觸發 (trip) 狀態。

成功的實機硬體命令執行後，Live Data 可能會更新一次。它維持唯讀屬性，應被視為所顯示儀器狀態的權威來源。

PSM-2010 的 CH1 卡片會額外顯示目前實際 LOW/HIGH 輸出檔位的唯讀 badge。尚未知或尚未取得資料時顯示 --；其他型號不顯示此 badge。

基本命令 (Basic Commands)

Basic command 面板用於常見的各通道設定點與輸出動作。

Voltage 與 Current 欄位可以留空；空白欄位會從工作 payload 省略，Core 會保留原值。若要同時設定兩者，請填入兩個欄位後按下該通道的 Set。

輸出控制會依最新 Live Data 顯示下一個動作：輸出為 OFF 或未知時顯示 Turn on，輸出為 ON 時顯示 Turn off。亮起仍表示最新 Live Data 判定輸出為 ON；未亮不代表已確認 OFF，除非 Live Data 仍是最新狀態。

在 Real 模式，只要存在非空白 VISA 資源，Enable real hardware writes for this resource 預設會啟用並勾選。取消勾選可鎖定目前的資源與身分內容。切換或重新輸入資源、變更 Expected model、偵測到不同型號，或離開後回到 Real，都會建立新的內容並重新以允許寫入為預設。沒有資源時，該選項會停用，也不存在寫入授權。標題中的 Real · Writes locked／Real · Writes enabled 只是狀態顯示，不是控制項。

E3646A 不支援 CH1 與 CH2 各自切換輸出；兩個通道會顯示 Controlled by ALL，請使用 ALL 控制同時開啟或關閉輸出。CH1／CH2 的 Voltage、Current 與 Set 仍可分別設定。

啟用輸出前，請確認目標通道、設定安全的電流限制與電壓、透過 Live Data 或 readback 核對數值，並確認 DUT 能承受要求。

進階命令 (Advanced Commands)

使用 Show more commands 開啟命令列與自動生成表單。命令依 Output、Output Workflows、Protection、Trigger、Snapshot 與 Advanced Diagnostics 等用途分組。

必填欄位必須在 Run 前完成。停用的命令或控制項代表目前型號、模式或 WebUI 範圍不支援。停用原因是刻意的功能鎖定提示，不是隨機 UI 錯誤；產品級實機支援會依偵測型號、命令、transport、backend 與必要功能精確判定，缺少或 pending 的範圍都會 fail closed。

E3646A 的 Product LIVE 目前只涵蓋 ASRL／RS-232 + system VISA；其 ramp-list 與受限步驟的 sequence 是軟體工作流程，不是 native LIST。WebUI 僅提供 Product 模式，不提供 validation override；即使直接送出舊的或手工建立的 API 請求，Core 仍會重新執行精確支援檢查。

Sequence、Ramp List 與 Trigger List 等編輯器支援 JSON Load/Save。請勿把私人的實驗室資源字串存入要提交或分享的檔案，除非該檔案刻意只供本機使用。

Ramp 的 Channel selector 會依所選或偵測到的型號顯示各通道、支援的通道組合，以及多通道型號的 All。所選通道共用相同電流與電壓設定並以 lockstep 前進；只有每個所選通道都成功後，該電壓步驟才算完成。選取通道組合或 All 時，Channel 與 Current 下方會顯示一則全寬提示，說明共用參數與 lockstep 行為。選取單一通道時不會顯示提示，也不會在 Ramp 表單留下空白列。

Ramp List 可載入 v2 至 v5，儲存時一律輸出 v5。每個 Segment 都能選擇自己的通道組合；All 會寫成明確的 channels 清單。多通道 Segment 以 lockstep 前進，progress 與脈波仍以 logical voltage step 計算。E3646A 使用自動啟用輸出時，Ramp List 會先為清單中使用的每個通道寫入第一組安全設定值，再一次啟用全域輸出。

Ramp、Ramp List 與 Sequence 提供 Enable loop。啟用後 Loop count 可輸入 2 至 10,000，代表完整工作流程的總執行次數，而不是額外重複次數；關閉時等同執行一次。Ramp 與 Ramp List 只有在 Loop 啟用時才提供 Loop complete 脈波時機。Ramp List 儲存 v5，Sequence 儲存 v2，兩者都會明確寫入 loop_count，包含單次執行的 1。

工作結果 (Job Results)

送出的命令會出現在 Job Result。選取工作後，可在 Result Detail 檢查狀態與原始 JSON。

常見狀態包括 accepted、started、progress、finished、failed、cancel requested 與 cancelled。失敗工作應在結果 payload 中包含錯誤訊息。

Device options 提供 Simulate 與 Dry-run。這兩種模式會停用 VISA resource、掃描、序列連線設定與 Live Data，且不會開啟或鎖定真實硬體。Simulate 只能使用實體規劃型號；Dry-run 可使用實體規劃型號或非實體 planning profile。Real 模式的 runtime.expected_model_id 是可選安全護欄，不能選擇驅動程式或擴大支援範圍。

原始 JSON 採嚴格型別：布林欄位只接受 JSON true/false；字串 "false" 不會被當成確認。通道只接受正整數，且只有支援全通道的命令才接受精確字串 "all"；布林值、浮點數與數字字串都會被拒絕。缺少規劃身分、格式錯誤的 Snapshot／Restore，或未知及刻意不支援的命令，都會在建立工作或背景任務前被拒絕。

停止與取消

尚未開始的工作通常能立即取消。真實硬體工作已在執行時，取消採協作模式：WebUI 先提出取消請求，再等待目前 I/O 與 Core 的安全關閉、切回本機及清理流程完成。

除非有外部安全原因，請勿關閉瀏覽器或強制終止程序來中斷正常清理。

Quit 會要求取消目前所有 WebUI 工作（包含 Live Data），並等待正常清理後才停止本機伺服器。若清理或伺服器關閉在逾時前無法完成，啟動器會保持開啟並顯示 Shutdown incomplete，讓您處理問題後再次嘗試。

常見問題

頁面無法載入

確認伺服器仍在執行，並開啟啟動器顯示的實際 URL。若實際使用預設 port，範例為：

http://127.0.0.1:7999/

自動啟動可能選擇不是 7999 的 port，請以啟動器顯示的 URL 為準。

啟動器顯示 port 已被佔用

啟動器絕不會開啟已經占用候選 port 的服務。預設自動啟動會跳過 address-in-use 候選 port；固定 --port 發生衝突時會直接結束，不會選擇其他 port。若已開啟 manual fallback 視窗，請選擇其他 port，或停止占用所選 port 的服務後，再點擊 Start。

Scan Device 找不到任何東西

請檢查：

  • 儀器已開機；
  • USB、LAN 或適用的 ASRL／RS-232 連線已接妥；
  • VISA 驅動程式可辨識儀器；
  • 沒有其他程式占用資源；
  • 此電腦已安裝正確且可載入的 VISA 後端。

您仍可手動輸入已知的 VISA 資源。

執行 (Run) 被封鎖

請閱讀畫面上的驗證訊息與 Result Detail。常見原因包括缺少資源、必填欄位未完成、不支援的型號或精確連線範圍、不安全的設定點，或實機寫入授權／必要確認不足。選擇 Expected model 不會解鎖停用命令；它只用於無硬體規劃，或在 Real 模式檢查連線儀器的 *IDN? 型號。

輸出按鈕看起來不是最新狀態

啟動或重新整理 Live Data。WebUI 會避免將過時的輸出狀態當成最新的事實來顯示。

命令顯示忙碌中

真實硬體命令由 WebUI 的硬體鎖定進行序列化。請等待目前的命令與清理完成，或僅在這是操作員刻意要做的動作時才進行取消。

Live Data 回報過時或錯誤狀態

檢查資源、連線，以及是否有其他命令佔用了硬體 I/O。Live Data 不會覆蓋 (override) 真實的命令執行。

操作員安全注意事項

  • 在執行影響輸出的命令前，請使用唯讀的 Live Data。
  • 首次實機檢查應保持低電壓/電流，並明確指定通道。
  • 在啟用輸出前，確認電流限制。
  • 請將 channel all 視為刻意的多通道動作。
  • 在理解觸發 (trip) 原因前，請勿清除保護。
  • 將觸發與 LIST 工作流程視為進階操作。
  • 在可行情況下，斷開 DUT 之前請停止或關閉輸出。
